# Context Retrieval

What happens after the fetch: chunking, retrieval and citations for web RAG.

- **Website:** [contextretrieval.net](https://contextretrieval.net)
- **Blog:** [contextretrieval.net/blog](https://contextretrieval.net/blog) · **Guides:** [contextretrieval.net/guides](https://contextretrieval.net/guides)
- **Docs:** [contextretrieval.net/docs](https://contextretrieval.net/docs)
- **CLI:** [`contextretrieval`](https://github.com/contextretrieval-net/cli), live web pages as Markdown from your terminal ([docs](https://contextretrieval.net/docs/cli), [npm](https://www.npmjs.com/package/@contextretrieval-net/cli))

```bash
npx @contextretrieval-net/cli fetch https://example.com -o text
```
